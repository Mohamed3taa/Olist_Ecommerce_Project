## 🧠 Project Overview

This project delivers a complete end-to-end data analytics pipeline using the Olist E-commerce dataset. It includes every step of the data lifecycle — from **raw data cleaning** and **transformation**, to **advanced visualizations** and an **interactive dashboard**.

## 🧱 Project Structure

| Folder | Description |
| :--- | :--- |
| `01_Raw_Data` | Original raw CSV files from Kaggle. |
| `02_SQL` | SQL scripts for data cleaning, handling nulls, trimming spaces, and creating cleaned views. |
| `03_Cleaned_Data` | Cleaned SQL views exported as CSV files. |
| `04_Python_Notebooks` | Data preprocessing and Exploratory Data Analysis (EDA) notebooks. |
| `05_BI_Tools` | Power BI dashboards and static visual reports. |
| `06_Streamlit_App` | The Python code and requirements for the Streamlit web application. |
| `07_Documents` | Project documentation, presentations, and screenshots. |

## 🧰 How to Run Locally

To run the Streamlit dashboard on your local machine:

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/YourUsername/Olist_Ecommerce_Project.git](https://github.com/YourUsername/Olist_Ecommerce_Project.git)
    ```
2.  **Navigate to the App Folder:**
    ```bash
    cd Olist_Ecommerce_Project/06_Streamlit_App
    ```
3.  **Install Dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
4.  **Run the App:**
    ```bash
    streamlit run app.py
    ```
